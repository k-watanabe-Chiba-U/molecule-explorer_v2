# 公開用XYZフォルダ

この `molecules` フォルダに `.xyz` ファイルを追加・削除するだけで、GitHub Pagesの分子一覧が自動で更新されます。ファイル名がそのまま分子名として表示されます。

- GitHubでこのフォルダを開き、`Add file` → `Upload files` → `.xyz` を選んで `Commit changes`。
- Webサイトへの公開が完了したら（通常数分、最大10分程度）ページを再読み込みし、「↻ 更新」を押してください。
- `hydrogen.xyz` は表示確認用の例です。不要になれば削除できます。
- 本サイトは公開されます。未発表の構造、機密研究データ、生徒の個人情報を含むデータはアップロードしないでください。
- XYZ形式：`原子数`、`コメント`、`元素記号 x y z` を原子数分の行。単位は Å。複数フレームも可。
